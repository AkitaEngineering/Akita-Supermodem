# PSK And Artifact Signing Runbook

This runbook covers operational key handling for secure field trials.

## PSK Requirements

`AKITA_SUPERMODEM_PSK` is required for every network profile. Treat it as a
shared mission secret. The runtime rejects secrets shorter than 16 bytes.

Recommended PSK properties:

- At least 32 random bytes before encoding.
- Generated by a password manager or operating-system CSPRNG.
- Unique per team, deployment, or mission window.
- Never committed to source control, logs, screenshots, or mission artifacts.
- Rotated after field tests, suspected exposure, personnel changes, or lost
  equipment.

Example generation:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Set it on both endpoints:

```bash
export AKITA_SUPERMODEM_PSK="paste-generated-secret-here"
```

## Rotation

1. Generate a new PSK.
2. Load it on both endpoints before field operations.
3. Run a short ground transfer test.
4. Remove the old PSK from shell history, service files, and field notes.
5. Record the rotation date and deployment identifier in private operations
   records.

## Revocation

If a PSK is exposed:

1. Stop field transfers.
2. Generate a replacement PSK.
3. Update every authorized endpoint.
4. Mark any files received during the exposure window as untrusted until
   independently validated.

## Artifact Signing

Supermodem verifies transport integrity, but mission software should still treat
received files as untrusted input. For mission-critical artifacts, verify a
separate Ed25519 signature before use.

Available helpers:

```python
from akita_supermodem.artifact_signing import verify_file

if not verify_file(public_key_bytes, "mission.json", signature_bytes):
    raise ValueError("Mission artifact signature failed")
```

Recommended policy:

- Store public verification keys on the aircraft or companion computer.
- Keep private signing keys off aircraft unless the aircraft must sign data.
- Sign mission plans, geofences, firmware bundles, and configuration artifacts.
- Verify schema, bounds, and mission safety after signature validation.
